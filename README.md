# MiniHTTPd - Servidor Web EPN

Proyecto integrador de Redes de Computadoras. Es un servidor HTTP/1.1 desarrollado en C para Linux, capaz de servir contenido estático.

## Avance Actual
- Estructura base del proyecto.
- Configuración inicial de sockets y transporte.
- Archivos estáticos de prueba (HTML, CSS, PNG).

## Cómo compilar y probar
1. Compilar el proyecto:
   `make`
2. Ejecutar el servidor:
   `./minihttpd 8080`
3. Probar en el navegador o terminal:
   `http://localhost:8080/`
